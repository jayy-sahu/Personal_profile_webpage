🌐 **Personal Profile & University Website**

A responsive multi-page website developed using HTML and CSS. This project showcases my personal profile, professional resume, and university information in a simple and attractive design. This project is designed to present personal information, educational qualifications, technical skills, and university facilities through three separate web pages.
The website provides easy navigation between the Profile Page, Resume Page, and University Page.

✨ **Features**

1. **Personal Profile Page**
- Displays personal profile information.
- Profile picture section.
- BCA department information.
- Navigation buttons to Resume and University pages.

2. **Resume Page**
- Professional resume layout.
- Personal contact information.
- Career Objective.
- Educational Qualification.
- Technical Skills.
- Academic Project Details.
- Profile photo section.
- Back to Profile button.
- Fixed-size layout with internal scrolling.

3. **University Page**
- Anjaneya University introduction.
- University logo and campus image.
- Navigation bar.
- Facilities section:
  - Sports
  - Library
  - Laboratories
  - Transportation
- Social media links.
- Back to Profile button.
- Fixed-size layout with internal scrolling.
